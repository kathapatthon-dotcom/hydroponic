ระบุกรอบเวลาที่แน่นอนเพื่อให้ปั๊มน้ำขนาดเล็กทำงานโดยตรง เหมาะสำหรับผู้ใช้ที่ไม่มีเวลาว่างและต้องการดูแลความชื้นต้นไม้

โครงสร้างเวลาที่บันทึกแล้ว: จะสั่งรดน้ำอัตโนมัติทุกวันในเวลา --:-- น.

การทำงานฝั่ง MCU (Arduino Concept)

void loop() {
  String current = timeClient.getFormattedTime().substring(0,5);
  if (current == "--:--") {
    digitalWrite(RELAY_PIN, HIGH); // เปิดวาล์วปั๊มน้ำ
  }
}
